# Lá Fora

A small field notebook for noticing nature near home. Choose a few minutes, a familiar place, and how you want to observe. The app prepares a short mission; when you return, you can write down what you noticed.

## Project status

The app is being built for the DEV Hacktoberfest Open-Source AI Challenge, Week 1: Touch Grass. This repository is new and work is in progress.

## Development

Requirements and setup instructions will be added as the app is implemented. Copy `.env.example` to `.env` and provide a Gemini API key with access to the Gemma model. Keep `.env` private.

## Privacy

The planned app stores the last mission and field note in the browser on your device. A mission request sends its selected options and optional context to the configured model provider. Do not enter private or sensitive information.
